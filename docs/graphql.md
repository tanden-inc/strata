# GraphQL

*Design note. Status: planned (not in 0.1).*

The mapping Strata intends to ship in `strata/graphql`:

| Strata | GraphQL |
|---|---|
| a `suberror` (closed set of typed rejections) | a result union (`MoveResult = Moved | Insufficient | ...`) |
| `Selection` + `Runtime::read` (paged, cursor = `Position`) | a connection |
| `Runtime::subscribe` | a subscription |
| `Outcome.version` | `ETag` / `expectedVersion` argument |
| `Projector::wait_for(out.position)` | read-your-writes in the mutation resolver |

MoonBit's `derive` covers a fixed set of traits, so the SDL and resolver skeletons will be generated by a `moon run`
tool from your enums and suberrors and checked in. A renamed variant then fails the build, but the "no codecs, no
registries" promise of the storage format does not extend to the public schema.

Open questions: cursor encoding, N+1 over keyed projections, error mapping for `AppendConflict`.
